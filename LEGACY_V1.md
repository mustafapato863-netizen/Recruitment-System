# Legacy v1 UI snapshot (reference only — do not merge)

This branch (`legacy/v1-ui`) is a snapshot of RecruitFlow `main` at `a1682ad`
("Merge RecruitFlow batch 2 frontend v2 (#2-#30)"), the last commit where the
v1 UI (pages, routes, layouts and the v1/v2 switches) is still complete.

It is kept so the v1 screens can be consulted or run after `feature/v2-default`
removes them from `main`. It is **not** a release line and must never be merged.

Run it like main: `pnpm install && pnpm --filter web dev`.
