# Approved reference pack

This folder contains the approved planning materials supplied for RecruitFlow. It is intentionally separate from runtime code.

The retired generated UI/UX prototype and screenshot pack has been removed. Use the frontend simple system plan for current frontend direction.

## Reading order

1. [Planning pack](planning/README.md)
2. [Frontend simple system plan](../development/FRONTEND_SIMPLE_SYSTEM_PLAN.md)

The business requirements and workflow/status matrix define the product rules. The data dictionary defines the relational model. The screen requirements define interaction expectations. The technical guidelines define the engineering baseline.
