# Approved reference pack

This folder contains the planning and visual materials supplied for RecruitFlow. It is intentionally separate from runtime code.

## Reading order

1. [Planning pack](planning/README.md)
2. [UI/UX prototype](ui-ux/README.md)

The business requirements and workflow/status matrix define the product rules. The data dictionary defines the relational model. The screen requirements define interaction expectations. The technical guidelines define the engineering baseline.
