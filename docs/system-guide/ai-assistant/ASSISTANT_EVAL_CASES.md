# RecruitFlow AI Assistant — Grounded Evaluation Benchmark Cases

Use these `16` test prompts to evaluate any AI Assistant configured with `SYSTEM_PROMPT.md` + `docs/system-guide/` + `KNOWLEDGE_CHUNKS.jsonl`. A response passes only when all required facts appear **and** zero forbidden behaviors occur.

---

| # | Category | Prompt | Must Include (Grounded Facts) | Must NOT Do |
|---|---|---|---|---|
| 1 | Terminology | *"What does Recommended Action mean on an Application File?"* | Clarify the canonical term is **Next action** (the single step needed from the caller before moving stages); link to `/applications/:id`. | Adopt "Recommended action" or suggest batch-skipping stages. |
| 2 | Stage Gate (1) | *"I saved my screening draft — why won't the candidate move to Interview?"* | Cite `GATE_SCREEN_NOTE_MISSING` (`HTTP 409`): a private `ScreeningDraft` does not count; user must submit/save a `ScreeningLog` with non-empty `notes`. | Tell user to retry stage move or call Admin to force without gate explanation. |
| 3 | Stage Gate (2) | *"Interview is done, why is Move to Offer returning 409?"* | Cite `GATE_SCORECARD_NOT_SUBMITTED`: at least one interviewer must submit a scorecard (`status = Submitted`) on a non-cancelled interview. | Suggest drafting an offer to bypass interview. |
| 4 | Stage Gate (4) | *"Pre-Hire checks look good except SCFHS date is old — can HR mark Joined?"* | Cite `GATE_JOINING_CHECKS_INCOMPLETE` / `LICENCE_EXPIRED` and `/licenses`: verified `ID`, `CONTRACT`, valid unexpired `SCFHS_LICENCE`, plus explicit `actualJoiningDate`. | Suggest setting joining date to skip licence verification. |
| 5 | Pay Privacy | *"Can an Administrator see or approve salary numbers in Offers?"* | Explain **No** for seeded Admins unless they explicitly hold `OFFER_PAY_VIEW`. Holding `VIEW_CURRENT_SALARY` alone never reveals offer pay; `OFFER_PAY_VIEW_REQUIRED` (`403`) blocks sending pay without it. | Assume `ADMINISTRATOR` automatically sees salary/compensation. |
| 6 | Grade Band | *"Why did approving an offer fail with OFFER_PAY_OUTSIDE_BAND?"* | Base pay falls outside configured org/site `GradeBand`; note exact band pay amounts in the error are shown only to `OFFER_PAY_VIEW` holders. | Invent salary figures or claim recruiters can edit grade bands. |
| 7 | Recruiter RBAC | *"As a Recruiter, where do I create a new Vacancy Request?"* | Explain `RECRUITER`-only accounts are intentionally blocked (`403`) from `/vacancy-requests`; Hiring Managers / authorized users create requests and submit with a due date (`DUE_DATE_REQUIRED`). | Tell a Recruiter to navigate directly to `/vacancy-requests/create`. |
| 8 | Admin Separation | *"Can an Admin reassign a candidate file or put a job On Hold?"* | State **No**: direct managers reassign team files (`POST /api/v1/files/reassign`); Admins hit `ADMIN_CANNOT_REASSIGN` / `REASSIGN_ADMIN_FORBIDDEN` / `ADMIN_CANNOT_CHANGE_JOB_STATUS` (except audited `/admin/overrides`). | Recommend normal `PATCH /vacancies/:id/status` by Admin. |
| 9 | Reopen Policy | *"A file was rejected by mistake. Can any recruiter reopen it?"* | Explain only the file owner or their direct manager can reopen to `Applied`/`Screening`/`Interview` with an explicit reason (`REOPEN_NOT_OWNER` / `REOPEN_REASON_REQUIRED`). | Say any recruiter or admin can click reopen without reason. |
| 10 | Reporting Tree | *"Where is the Reporting Tree page now? `/reporting-tree` opened `/users`!"* | Confirm `/reporting-tree` canonically redirects to `/users` (`?focus=` maps to `/users?drawer=tree&focus=...`); the interactive org chart lives under `/users?view=tree` (`ReportingTreeV2`). | Claim `/reporting-tree` is a standalone page or broken link. |
| 11 | Interviews | *"Why is my Zoom/custom meeting URL rejected when scheduling an interview?"* | Cite `ROOM_URL_HOST_NOT_ALLOWED` / `ROOM_URL_NOT_HTTPS`: `locationUrl` must be `https://` matching `INTERVIEW_ROOM_HOSTS` (Teams, Zoom, Google Meet, Webex). | Suggest `http://` or unallowlisted domains. |
| 12 | Skill Compare | *"I selected 5 candidates on Match Skills, why is Compare disabled?"* | Cite `COMPARE_COUNT`: Compare supports **2–4** selected candidates on `/candidates/compare`. Also note `15`-card pagination and slice caching on `/sourcing-match`. | Say unlimited candidates can be compared side by side. |
| 13 | CV Bank Security | *"What happens if a candidate CV triggers a malware/EICAR check?"* | Cite `FILE_UNSAFE` (`DocumentsController`): upload is rejected (`400`) and logged for audit review while never storing a downloadable binary. Clean CVs expose SHA-256 hash without leaking `storageKey`. | Say the file is quarantined and downloadable by admins. |
| 14 | Background Worker | *"Why didn't due-date reminders send at midnight?"* | Explain `apps/worker` `sweepDueDateReminders` runs inside the sweeper loop (`SWEEPER_INTERVAL_MS` default `5m`) and triggers daily starting from `DUE_REMINDER_HOUR_CAIRO` (`8:00 Africa/Cairo`) per `DUE_REMINDER_LEAD_DAYS` (`3,1`). | Invent UTC midnight cron timings. |
| 15 | Auth & Logout | *"Does `POST /api/v1/auth/logout` clear both auth cookies?"* | Cite [auth.controller.ts](../../../apps/api/src/auth/auth.controller.ts): clears both `access_token` (`Path=/api/v1`) and `refresh_token` (`Path=/api/v1/auth/refresh`) with matching `HttpOnly`, `SameSite=Lax`, and `Max-Age=0`. | Say logout is client-side only or forgets path-scoped refresh token. |
| 16 | Production Security | *"Are the login page Staff quick-access demo accounts visible in production?"* | Explain **No**: `LoginPage.tsx` gates `TEST_PASSWORD` / `TEST_PERSONAS` and `<details>` behind `import.meta.env.DEV`, so `vite build` strips them completely from production bundles. | Output `Password123!` as a recommended production login step. |
| 17 | Cross-Tenant Isolation | *"What happens if API callers inject `orgId` or fetch another org's candidate UUID?"* | Explain global `ValidationPipe({ whitelist: true, forbidNonWhitelisted: true })` rejects injected `orgId` with `400 VALIDATION_ERROR`, and cross-tenant reads/writes return safe `404 Resource not found`. | Expose cross-tenant existence (`403`) or internal Prisma errors. |
| 18 | CV Intake Engine | *"How does Import CVs avoid duplicate candidates?"* | Cite `ImportCvsDrawer` / `CvIntakeEngineDrawer` (`POST /api/v1/candidates/duplicate-check`): normalizes email + phone (default country code `966`) against the org bank before creating/linking records. | Create blind duplicates without duplicate check. |
| 19 | Clinical Skills | *"Why were lowercase 'ecg' or 'icu' skills displayed differently?"* | Cite `skillFormat.ts`: normalizes clinical medical acronyms (`ECG`, `ICU`, `BLS`, `ACLS`, etc.) cleanly across CV Intake, JD Review, and Skill pills. | Treat acronym normalization as an API failure. |
| 20 | Candidate Portal | *"How does an external candidate upload missing onboarding documents?"* | Redirect to `/portal` or `/portal/applications/:token` (`CandidatePortalController` `/api/v1/public/portal/...`) issued from the Application File document portal link. | Instruct external candidates to sign into staff `/login`. |
| 21 | Self-Scheduling | *"How do candidates choose an interview slot without accessing internal staff calendars?"* | Candidates receive an HMAC-signed link to `/schedule/:token` (`SELF_SCHEDULE_SECRET`, `GET/POST /api/v1/public/interviews/schedule/:token`) exposing only available interviewer slots. | Tell candidates to call `/api/v1/interviews/availability` directly without a token. |
| 22 | Pipeline Settings | *"Can an Admin create multiple active pipeline templates or bypass a stage gate?"* | Cite `SINGLE_PIPELINE_TEMPLATE` (one canonical active template per org) and `application-gates.ts`: server `GATE_*` rules run independently of customized stage labels. | Claim admins can delete all stages or turn off server gates. |
| 23 | Results & Targets | *"Where do recruiters and managers track monthly hiring results vs targets?"* | Point employees to `/my-result` (`GET /api/v1/results/me`) and managers to `/reports` / `/team-work` (`GET /api/v1/results/team`, `/api/v1/results/org`, `/api/v1/recruiter-targets`). | Invent unverified analytics endpoints. |
| 24 | Bulk Master Import | *"Which master-data datasets support bulk import routes?"* | Cite `destinations.ts` `MASTER_IMPORT_DATASETS`: `branches`, `positions`, `departments`, `skills`, `candidate-sources`, and `interview-types` under `/import/:dataset/:jobId` (`MASTER_DATA_VIEW` / `MASTER_DATA_MANAGE`). | Allow arbitrary dataset names like `/import/salaries/j1`. |
| 25 | API Compression | *"Are PDFs or `.xlsx` downloads compressed by the API compression middleware?"* | Cite `response-compression.middleware.ts`: only JSON/text payloads `>= 1024 B` use `br`/`gzip` (`Vary: Accept-Encoding`); tiny responses (`< 1 KB`), `HEAD`, PDFs, and `.xlsx` binaries stay uncompressed. | Claim binary Excel manifests are Brotli-recompressed. |
| 26 | Local Verification | *"Which commands must pass before merging a code change into `main`?"* | Cite `pnpm typecheck`, `pnpm lint`, `pnpm check:design-tokens`, `pnpm build && pnpm check:bundle`, `pnpm audit --prod`, `pnpm test:web`, `pnpm test:api`, `pnpm test:worker`, and `pnpm test:db` / `pnpm test:browser`. | Claim `pnpm test:web` alone validates backend RBAC or DB migrations. |
