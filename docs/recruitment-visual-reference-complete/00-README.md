# Recruitment Visual Reference - Integrated Set

This folder contains the deduplicated, numbered recruitment UI references in workflow order.

## Primary workflow
01 My Work Dashboard -> 02 Job Positions -> 03 Job Overview -> 04 Applications Pipeline -> 05 Applicant Profile -> 06 Stage Transition -> 09 Interviews -> 10 Interview Detail & Feedback -> 11 Offers -> 12 Offer Detail / Hire.

## Supporting views
13 Applications List View, 14 My Work Full Task Queue, 15 Job Analytics, 07 Recruitment Reports Dark, 16 Recruitment Settings, 08 Mobile Navigation / My Work.

## Reference boundary
- Visual direction: Saudi German Health / RecruitFlow design language used in the supplied and generated screen references.
- Workflow concepts: Odoo Recruitment documentation (job-position-first flow, configurable stages, Kanban applicant progression, interview scheduling, offer/contract progression and activities).
- The product should use official Saudi German Health brand assets/guidelines for production logo geometry and brand compliance.
