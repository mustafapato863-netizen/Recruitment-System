# RecruitFlow UI/UX Application v2.0

A comprehensive offline UI/UX prototype for the end-to-end recruitment workflow.

## Start
Open `app/index.html` in a browser. Every card opens an interactive HTML screen.

## Included
- 45 desktop feature screens
- 4 mobile workflow screens
- Dark-mode reference
- Four annotated feature-anatomy screenshots
- Screen catalog contact sheets
- Original UI reference images
- Feature-to-screen map and screen index

## Core workflow
Vacancy Request → Approval → Active Vacancy → Candidate/Application → Screening → Interviews → Hiring Decision → Offer/Version Approval → Hire Management → Documents/License → Final Hiring Approval → Awaiting Joining → Joined.

## Important design rules
- Position and Vacancy are separate entities.
- Candidate identity and Application workflow are separate.
- Stage, score, source and offer belong to the Application.
- Primary Recruiter is separate from Current Task Owner.
- Offer versions are immutable after approval.
- Documents and licenses use checklists and review states.
- Final Hiring Approver is configurable; no personal name is hard-coded.
- Joined requires an actual joining date.
